# Frontier Command Centre: Your first ten minutes

You have finished the [quick start](../README.md#1-quick-start-try-it-with-sample-data) and loaded the sample data. This is a short tour of Acme Corp, the fictional organisation it contains, in the order of the menu. Each step takes a minute or two.

1. **Dashboard.** Start with the briefing: what changed this week and what to do next, written by AI from Acme's figures, with the recommendations and the organisation risk score.
2. **Alerts.** Personal data and risky intent flagged in Acme's prompts, each with the evidence.
3. **Work Pulse.** How deeply Acme's people hand work to Claude, from routine tasks (Tier 1) to whole processes (Tier 3), and whether that is spreading across departments or sits with a few people. Open a department to see its people and where to coach.
4. **Developer Pulse.** What Claude Code produces for Acme's engineers: engaged time, lines of code, commits, pull requests and accepted edits, beside what it costs.
5. **Use Cases.** Find the month-end variance commentary process that several Finance colleagues repeat. Open it and select **Turn this into a skill** to see Command Centre draft it as a reusable Claude skill.
6. **S&C Board.** The skills and connectors Acme's people already use, who owns each one and how widely it has spread.
7. **FinOps.** Acme's AI spend by department, cost centre, kind of work and model. Then open **Spend Review** to see who spends what, who is most efficient, and who has a cheaper route to the same work.
8. **Audit Log.** Every prompt from Claude Cowork, Claude Code and Claude Chat in one searchable trail.
9. **Admin.** Where an administrator runs Command Centre: add people and set their roles and departments, add the Claude API key and other keys, check that Claude's activity is arriving, tune the tiers that grade work and the models each AI feature uses, set alert thresholds and Slack alerts, switch features such as FinOps and Use Cases on or off, set how long data is kept, and check that every scheduled job is healthy. [The admin pages](product-overview.md#the-admin-pages) describes each page.

When you are ready to see your own organisation, install Command Centre on a server and [connect Claude for Teams](../README.md#2-connect-claude-for-teams) or [Claude for Enterprise](../README.md#3-connect-claude-for-enterprise).
