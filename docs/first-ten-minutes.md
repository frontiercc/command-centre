# Frontier Command Centre: Your first ten minutes

You have finished the [quick start](../README.md#1-quick-start-try-it-with-sample-data) and loaded the sample data. This is a short tour of Acme Corp, the fictional organisation it contains, in the order of the sidebar. You are signed in as an admin, so you see every page. Each step takes a minute or two.

Work is graded on three tiers, named Administrative, Meaningful and Frontier unless an admin renames them. The pages use those names.

1. **Dashboard.** Start with the briefing: what changed this week and what to do next, written by AI from Acme's figures, with the recommendations and the organisation risk score. The briefing needs your Claude API key: without one, the panel asks you to add it under Admin → Access & Keys. Below it are this week's figures and the departments.
2. **Alerts.** Personal data and risky intent flagged in Acme's prompts, each with the evidence.
3. **Ask the data (preview).** Ask a question in your own words, such as which department spent most this month, and get an answer built from the pages' own figures, with links to those pages. It is off until an admin turns it on under Admin → Ask the data, it is for admins only, and it needs the Claude API key. Each question, and the page figures it needs, go to Anthropic's Claude API; the answer is not stored. [AI data flow](ai-data-flow.md#ask-the-data) has the detail.
4. **Work Pulse.** How deeply Acme's people hand everyday work to Claude and ChatGPT. **Overview** shows whether people are handing over bigger jobs, which departments do the deepest work, what the work produced, and which products people use, from Claude Chat, Claude Cowork and Claude in Excel, Word, PowerPoint, Outlook and Google Sheets, Docs and Slides to ChatGPT. **My Pulse** is one person's own work, **Users** opens anyone's, and **Departments** shows one department's work, its people and where to coach.
5. **Work Pulse So What.** Pick a team and a question: they want to hire, or someone has left. Each answer is a card: the gap between the team's best people and everyone else, what closing it is worth, a recommendation and two buttons to decide. The page also finds cards of its own. A decided card comes back 30 days later with what has happened since.
6. **Work Pulse Team Coaching.** Pick a team to see where it is, what to work on, who to learn from and what to try. Mark an action done, and the page later says whether the figure it was meant to move did, against the organisation's own movement over the same time.
7. **Developer Pulse.** What Claude Code and Codex produce for Acme's engineers, beside what each costs: commits and actions from both, and engaged time, lines of code, pull requests and accepted edits from Claude Code. **Overview** covers everyone, **My Developer Pulse** one person, and **Users** and **Departments** anyone's or one department's. **Value** is an estimate of the value created, with time saved counted from pull requests and commits only.
8. **Developer Pulse So What.** The same questions as Work Pulse So What, answered from Acme's engineers and their coding work.
9. **Developer Pulse Team Coaching.** A coaching plan for one engineering team, and whether what they did moved the figure.
10. **Use Cases.** On **Overview**, find the month-end variance commentary process that several Finance colleagues repeat. Open it and select **Turn this into a skill** to see Command Centre draft it as a reusable Claude skill. **Governance** shows the use cases Acme has declared and their measured outcomes.
11. **S&C Board.** The skills and connectors Acme's people already use, who owns each one and how widely it has spread. Open an entry to see who uses it, its use in the last seven days and how to install it.
12. **FinOps.** Acme's AI spend by cost centre for the month. **Where it goes** splits it by product. Then open **Spend Review** to see what each person's spend goes on, who is most efficient, and who has a cheaper route to the same work. FinOps is for admins and managers only.
13. **Audit Log.** Every prompt from Claude Cowork, Claude in Office/Google, Claude Code, Claude Chat, ChatGPT and Codex in one searchable trail. Use the Product filter to see one product, such as Excel, a Google app or ChatGPT.
14. **Admin.** Where an administrator runs Command Centre. Add people and set their roles and departments, and add the Claude API key and other keys. Check that activity from Claude, ChatGPT and Codex is arriving. Tune the tiers that grade work, the models each AI feature uses, and alert thresholds and Slack alerts. Switch features such as FinOps, Use Cases and Ask the data on or off, set how long data is kept, and check that every scheduled job is healthy. [The admin pages](product-overview.md#the-admin-pages) describes each page.

So What and Team Coaching are for admins and managers. A manager sees their own department.

When you are ready to see your own organisation, install Command Centre on a server and connect Claude ([Teams](../README.md#2-connect-claude-for-teams) or [Enterprise](../README.md#3-connect-claude-for-enterprise)), [ChatGPT and Codex](../README.md#4-connect-chatgpt-and-codex), or both.
